# EGP Window v1.0.0 — Release notes

> **W11 F13.5.** Prod cutover release. Signed by SA + PE + QA + BIX + PM.

## Overview

Port of the LangGraph clinical-genomics prototype to **Microsoft Agent
Framework 1.10.0** on Azure Container Apps, backed by Postgres Flex +
Cosmos DB + APIM + Foundry.

## What's new (workstream by workstream)

| WS | Delivery | Sign-off |
|---|---|---|
| **W01 — Foundation** | DI container, Settings, Postgres pool factory, Cosmos client factory, prompt service, structured logging. | SA, BE1 |
| **W02 — Clinical Data Layer** | Postgres schema (Alembic), seed from DuckDB, `BaseRepository`, `ProvenanceService`, `AllowlistAuthzPolicy`. | DE, BE2 |
| **W03 — Domain Repositories & Tool Shims** | 5 domain repositories + 14 `@tool`-decorated shims + family-history privacy strip. | BE2 |
| **W04 — MAF Workflow Skeleton** | Chat + orchestration workflows on MAF; `SpecialistDispatchSet` decision; fan-out/fan-in dormant at width 1; recursion budget = 12. | BE1 |
| **W05 — Specialist Agents** | 5 specialists (`SpecialistBase` template); MAF-backed `SpecialistLlm`; provenance attached per row. | BE2 |
| **W06 — Parallel Execution & Mode-Parity** | `ORCH_DISPATCH_MODE` env var; sequential↔parallel mode-parity harness. | BE1, QA |
| **W07 — Authentication & Authorization** | Entra ID JWT via PyJWT + JWKS; `ClinicianContext`; structured `AuditEvent`; app-role check. | SEC, SA |
| **W08 — Observability** | OTEL SDK + 7 span kinds + 10 KPI metrics + PHI-safe attribute allowlist + provenance-trace correlation. | PE, SA |
| **W09 — Resilience & Error Handling** | Typed error taxonomy + `RetryingSpecialistLlm` + DB pool retries + specialist-failure isolation + response formatter. | BE1, SA |
| **W10 — Testing, Evaluation & Load** | Golden-set schema + 8-item seed + deterministic + LLM-judge scorers + PHI-safety CI detector + load/chaos runbooks. | QA, BIX |
| **W11 — Cutover, Release & Runbooks** | FastAPI HTTP layer; APIM retry + circuit-breaker; alerts Bicep; 3 dashboards; 8 runbooks; prod bicepparam; GHA deploy workflow; this release notes. | PE, SA |
